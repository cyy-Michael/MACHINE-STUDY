## 登记要求

1. 不直接在算法文件里写死文件路径。
2. 在数据层把原始字段转换为 `X` 和 `y`，并明确标签列。
3. 类别字段先编码，数值字段检查缺失值和异常值。
4. 训练/测试划分固定随机种子；标准化统计量只从训练集计算。
5. 最终报告中的样本数、字段数和标签名称必须与登记表一致。
